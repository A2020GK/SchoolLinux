# SchoolLinux Website

Мобильный веб-сайт-визитка для проекта SchoolLinux, посвященный представлению проекта и его возможностей.

## Структура

```
website/
├── src/
│   ├── components/
│   │   ├── Header.tsx         # Навигационная шапка с роутингом
│   │   ├── Footer.tsx         # Подвал с информацией о проекте
│   │   └── FeatureCard.tsx    # Компонент карточки функции
│   ├── pages/
│   │   ├── Home.tsx           # Главная страница с всеми секциями
│   │   ├── Home.css           # Стили главной страницы
│   │   ├── About.tsx          # Страница о проекте
│   │   └── About.css          # Стили страницы о проекте
│   ├── App.tsx                # Главный компонент с маршрутизацией
│   ├── index.css              # Глобальные стили (тема, компоненты)
│   └── main.tsx               # Точка входа React приложения
├── index.html                 # HTML шаблон
├── package.json               # Зависимости и скрипты
├── tsconfig.json              # Конфигурация TypeScript
├── tsconfig.app.json          # Конфиг TypeScript для приложения
├── vite.config.ts             # Конфигурация Vite
└── README.md                  # Этот файл
```

## Технологии

- **React 19** - UI библиотека
- **React Router v6** - маршрутизация между страницами
- **TypeScript** - типизированный JavaScript
- **Vite** - быстрый сборщик
- **CSS3** - стилизация (mobile-first подход)

## Стиль и дизайн

Использует единую цветовую схему с основным проектом SchoolLinux:

- **Основной цвет**: `#0f1512` (тёмный зелёный/чёрный)
- **Акцент**: `#5da57b` и `#7abd95` (зелёный)
- **Текст**: `#e7efe8` (светлый)
- **Фон**: Радиальный градиент с тёмным оттенком

## Разделы

### Главная страница (/)
- **Hero секция** - Заголовок, описание, кнопки действия
- **Функции** - Сетка из 6 карточек с основными возможностями
- **Проблема/Решение** - Описание контекста проекта
- **Режимы игры** - Два основных режима (Поиск, Создание)
- **Видео** - Placeholder видео-плеера (вы добавите видео позже)
- **Ресурсы** - Ссылки на:
  - Полное описание проекта (Google Docs)
  - Презентация (Google Slides)
  - GitHub репозиторий
- **CTA** - Call-to-action секция для установки

### Страница о проекте (/about)
- **Описание** - Что такое SchoolLinux
- **Технический стек** - Backend, Frontend, DevOps
- **Архитектура** - Объяснение компонентов системы
- **Функции** - Подробное описание каждой функции
- **Требования** - Системные требования для сервера, клиентов и сети
- **Установка** - Пошаговые инструкции с командами
- **Результаты** - Результаты апробации и тестирования
- **Об авторе** - Информация об авторе проекта

## Mobile-First подход

Все стили разработаны с расчётом на мобильные устройства:

- Используются `clamp()` функции для адаптивных размеров
- Медиа-запросы оптимизируют макет для мобильных устройств
- Гибкие сетки (CSS Grid) с автоматической перестановкой
- Сенсивные кнопки с достаточным размером для мобил
- Читаемые шрифты даже на маленьких экранах

## Как запустить

### Разработка

```bash
cd website
npm install
npm run dev
```

Откройте http://localhost:4000 в браузере.

### Продакшн

```bash
npm run build
npm run preview
```

Собранные файлы будут в папке `dist/`.

## Заполнение плейсхолдеров

Нужно заполнить следующие ссылки в компоненте `Home.tsx`:

1. **Видео**: Обновьте `src=""` в видео-теге на вашу ссылку
2. **Полное описание**: Обновьте первую ссылку в секции "Ресурсы"
3. **Презентация**: Обновьте вторую ссылку в секции "Ресурсы"

## Зависимости

Минимальный набор зависимостей для лёгкости и быстроты:

- `react` - основная библиотека UI
- `react-dom` - рендеринг React в DOM
- `react-router-dom` - маршрутизация между страницами

Никаких тяжёлых библиотек для иконок или компонентов - используются emoji для иконок!

## Цветовая схема

CSS переменные для всей темы:

```css
--bg-main: #0f1512;              /* Основной фон */
--bg-surface: #17221c;           /* Фон поверхностей */
--bg-surface-soft: #1d2a22;      /* Мягкий фон поверхностей */
--text-main: #e7efe8;            /* Основной текст */
--text-muted: #afbeb2;           /* Приглушённый текст */
--accent: #5da57b;               /* Основной акцент */
--accent-strong: #7abd95;        /* Сильный акцент */
--accent-soft: rgba(93, 165, 123, 0.28);  /* Мягкий акцент */
--danger: #d35d5d;               /* Цвет опасности */
```
